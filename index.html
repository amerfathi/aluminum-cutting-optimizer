لكل نوع نظام منطق ومقاطع تختلف تماماً عن غيره:

1. أنظمة السحاب (Sliding) ⬅ تتكون الدرفة من: [درفة جنب + درفة شنكل + درفة كعب]
اسم السيستم كود الحلق كود درفة جنب كود درفة شنكل كود درفة كعب عرض الدرفة (مم) خلوص الارتفاع (مم) تراكب العرض (مم) فرزة الزجاج (مم)
2. أنظمة الشبابيك المفصلية والقلاب (Casement Windows) ⬅ تتكون من: [حلق مفصلي + درفة مفصلي موحدة + باكتة زجاج]
اسم السيستم كود الحلق المفصلي كود درفة المفصلي كود باكتة الزجاج عرض بروفيل الدرفة (مم) خصم عرض الدرفة (مم) خصم ارتفاع الدرفة (مم) فرزة الزجاج (مم)
3. أنظمة الأبواب المفصلية (Doors) ⬅ تتكون من: [حلق باب 3 جهات + قائم باب + رأس وكعب باب سفلي + باكتة]
اسم السيستم حلق الباب (3 جهات) قائم الباب (Stile) كعب الباب السفلي باكتة الزجاج عرض قائم الباب (مم) خصم العرض (مم) خصم الارتفاع (مم)
4. الأنظمة الثابتة (Fixed Windows) ⬅ تتكون فقط من: [حلق ثابت + باكتة زجاج] (بدون أي درف نهائياً)
اسم السيستم الثابت كود الحلق الثابت كود باكتة الزجاج سماكة الفريم (مم) عمق فرزة الزجاج بالفريم (مم) خلوص الزجاج والكاوتشوك (مم)
