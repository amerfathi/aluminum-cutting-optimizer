أنظمة القطاعات المخصصة (مفصولة هندسياً حسب نوع النظام)

لكل نوع نظام منطق ومقاطع تختلف تماماً عن غيره:

1. أنظمة السحاب (Sliding) ⬅ تتكون الدرفة من: [درفة جنب + درفة شنكل + درفة كعب] SLIDING SECTIONS
2. أنظمة الشبابيك المفصلية والقلاب (Casement Windows) ⬅ تتكون من: [حلق مفصلي + درفة مفصلي موحدة + باكتة زجاج] CASEMENT SECTIONS
3. أنظمة الأبواب المفصلية (Doors) ⬅ تتكون من: [حلق باب 3 جهات + قائم باب + كعب باب سفلي + باكتة] DOOR SECTIONS
4. الأنظمة الثابتة (Fixed Windows) ⬅ تتكون فقط من: [حلق ثابت + باكتة زجاج] (بدون أي درف نهائياً) FIXED SECTIONS
