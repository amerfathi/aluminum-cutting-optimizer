# محسن قص الألمنيوم | Aluminum Cutting Optimizer

نسخة تجريبية (Prototype) لنظام تحسين قص بروفيلات الألمنيوم مع دعم خاص لقص الزوايا 45° و 90° وهالك السكراب.

## المميزات الحالية

- إدارة القطاعات (Profiles) مع تحديد سكراب خاص لكل زاوية
- إدخال القطع المطلوبة مع تحديد زاوية البداية والنهاية
- حساب سماكة السلاح (Kerf)
- طول العود قابل للتعديل (افتراضي 6000 مم)
- خوارزمية تحسين بسيطة (First Fit Decreasing)
- رسم تخطيطي للقص يوضح السكراب والقطع والمتبقي
- دعم كامل للغتين العربية والإنجليزية

## طريقة الاستخدام

1. افتح ملف `index.html` في المتصفح
2. أضف أو عدّل القطاعات والقطع
3. اضبط طول العود والـ Kerf
4. اضغط على **حساب وتحسين القص**

## التطوير المستقبلي

- تحسين خوارزمية القص
- دعم استغلال نهاية القطعة السابقة لتقليل السكراب
- تصدير PDF و CSV
- حفظ المشاريع
- دعم أكثر من نوع عود في نفس المشروع
