# محسن قص الألمنيوم والـ UPVC الاحترافي | Aluminum Cutting Optimizer Pro

نظام متطور وشامل لتحسين قص وتفصيل بروفيلات الألمنيوم والـ UPVC لورش ومصانع تصنيع النوافذ والأبواب والواجهات.

---

## 🌟 المميزات المتقدمة (v2.0)

### 1. 🧠 خوارزمية قص ذكية متقدمة (Smart Cutting Engine)
- **عزل القطاعات (Per-Profile Optimization):** تحسين مستقل ودقيق لكل نوع بروفيل (حلق، درفة، قاطع، باكتة...).
- **استغلال الزوايا المتطابقة 45° (Miter-Angle Matching):** تقليل الهدر والسكراب من خلال استغلال نهاية القطعة السابقة إذا كانت بنفس الزاوية بدون الحاجة لقصة سكراب إضافية.
- **خوارزميات توليف وبحث متعددة (Multi-Strategy Best Fit):** محاكاة مئات التوليفات لتقليل عدد الأعواد ونسبة الهدر الميت لأدنى حد ممكن.
- **قصة تنظيف بداية العود (Trim Cut) وسماكة السلاح (Kerf).**

### 2. ♻️ إدارة مخزون الفضلات والأعواد (Offcuts Inventory Management)
- جدول مخصص لتسجيل الفضلات المتوفرة بالمستودع بمقاساتها وزواياها ومواقعها.
- خيار ذكي: **استهلاك الفضلات المتوفرة أولاً** قبل فتح أعواد خام جديدة (6000 مم).
- زر فوري لـ **حفظ الفضلات الجديدة الصالحة للاستخدام** الناتجة من عملية القص وإضافتها للمخزون للمشاريع القادمة.

### 3. 📄 تصدير التقارير وأوامر التشغيل للورشة (Export & Reports)
- **تصدير ورقة قص فنية بصيغة PDF:** تحتوي على بيانات العميل والمشروع والترتيب المتسلسل للقص مع تعليمات الزوايا لكل قطعة.
- **تصدير ملفات Excel (.xlsx) و CSV:** جداول مفصلة للقص وجدول حصر الكميات والمواد (BOM).
- **تصميم مخصص للطباعة المباشرة (Print Ready View).**

### 4. 💾 إدارة وحفظ واستيراد المشاريع (Project Management & Sharing)
- حفظ المشاريع واسترجاعها محلياً عبر `LocalStorage`.
- تصدير ملفات المشاريع بصيغة `JSON` واستيرادها ومشاركتها بسهولة.
- منشئ قوالب سريعة للشبابيك والأبواب (2-Sash Sliding, Hinged Window, Hinged Door, Fixed Frame).

### 5. 🌐 واجهة تفاعلية وثنائية اللغة (Bilingual UI)
- دعم كامل ومتناسق للغتين العربية والإنجليزية (RTL / LTR) بضغطة زر واحدة.
- رسم تخطيطي تفاعلي لكل عود يوضح القطع، سماكة السلاح، السكراب، والفضلات المتبقية بالألوان.

## 🚀 طريقة التشغيل

1. افتح ملف `index.html` في أي متصفح ويب حديث مباشرة.
2. حدد إعدادات العود والسلاح وأضف القطاعات والقطع المطلوبة (أو استخدم القوالب السريعة).
3. اضغط على **"حساب وتحسين القص الذكي"**.
4. استعرض المخطط البياني، ثم اطبع ورقة العمل للفني أو قم بتصدير PDF / Excel.
